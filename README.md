# ОПИС МОЖЛИВОСТЕЙ 

Програма завантажується, показуючи меню, де розміщена вишивка з імені “DARIA” і дві кнопки.  

Натиснувши “ПРО СИМВОЛИ” - відкривається сайт, написаний самостійно за допомогою html та css з інформацією з відкритих джерел (джерело вказане), а саме користувач може прочитати про значення символів, кольорів і побачити приклади таких візерунків.  

Потім, натиснувши “СТВОРИТИ” відкривається головний екран з полотном, допоміжними інструментами для малювання, за допомогою яких можна створити власну схему для вишивки. Серед таких інструментів: вибір кольору з повною кольоровою гамою, піпетка (можна взяти з полотна вже існуючий на малюнку колір), заливка (спрацьовує на подвійний натиск), гумка (спрацьовує або кліком, або затиснутою кнопкою миші), пензль (так само як гумка). Додатково можна вибрати розмір пензля (на вибір 1-4), очистити полотно, скористатися симетрією - по горизонталі, по вертикалі та здублювати шаблон на полотні. Можна змінювати розмір полотна (мінімальний 1 на 1, максимальний 100 на 100), при цьому попередній малюнок зітреться. Якщо користувач напише недійсний розмір полотна - програма не дасть йому зберегти це.

З інших кнопок на екрані - зберегти схему та завантажити схему з файлів (працює тільки для файлів з цього застосунку) та повернутися до меню. Також під час застосування допоміжних інструментів для малювання вгорі підсвічується інструкція.
